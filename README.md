# Smart Parking Management System

## Overview
A C++ GUI application designed for parking receptionists
to manage vehicles, parking spaces, waiting vehicles,
parking fees, and parking records.

## Features
- Register vehicles
- Check parking slots
- Assign parking slots
- Manage waiting vehicles
- Calculate parking fees
- Process vehicle entry and exit
- View parking history
- View parking status

## Data Structures & Algorithms
- Circular Linked List
- Queue
- Binary Search Tree
- Binary Search
- Quick Sort
- Graph
